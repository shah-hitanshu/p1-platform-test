# Collaborative State System - Infrastructure

Local development infrastructure for the Collaborative State System using Cloudflare Workers, Durable Objects, PostgreSQL, and Firestore.

## Overview

This repository contains the **infrastructure configuration** for local development. It provides:

- **Docker Compose** configuration for backend services (PostgreSQL, Firestore emulator)
- **Terraform modules** for environment-consistent configuration
- **Wrangler configuration** for Cloudflare Workers with Durable Objects
- **Makefile** targets following Pantheon service template standards
- **Scripts** for local development workflow

Application code will be implemented separately following the architectural patterns defined in the PRD.

## Prerequisites

| Tool | Version | Installation |
|------|---------|--------------|
| Node.js | 20+ | [nodejs.org](https://nodejs.org/) |
| pnpm | 8+ | `npm install -g pnpm` |
| Docker | Latest | [docker.com](https://www.docker.com/) |
| Terraform | 1.6+ | [terraform.io](https://www.terraform.io/) |
| wrangler | 3+ | `pnpm add -g wrangler` |

Verify installation:
```bash
make version
```

## Quick Start

### 1. Clone and Install Dependencies

```bash
cd collaborative-state-system
make worker-install
```

### 2. Generate Local Secrets

```bash
make worker-generate-secrets
```

This creates `workers/.dev.vars` with mock credentials for local development.

### 3. Start Local Development

```bash
# Start everything (Docker + Miniflare)
make dev

# Or start components separately:
make docker-up      # Start PostgreSQL and Firestore emulator
make worker-dev     # Start Miniflare (in another terminal)
```

### 4. Verify Services

```bash
make dev-status
```

Expected output:
```
Docker Containers:
  css-postgres   running (healthy)
  css-firestore  running (healthy)

Service Endpoints:
  PostgreSQL:  localhost:5432
  Firestore:   localhost:8080
  Worker:      localhost:8787 (when running)
```

## Makefile Targets

### Local Development
```bash
make dev                  # Start all services (Docker + Miniflare)
make dev-docker-only      # Start Docker only
make dev-stop             # Stop all services
make dev-status           # Show service status
```

### Docker Services
```bash
make docker-up            # Start containers
make docker-down          # Stop containers
make docker-restart       # Restart containers
make docker-clean         # Remove containers AND volumes
make docker-logs          # Follow container logs
```

### Worker Development
```bash
make worker-install       # Install pnpm dependencies
make worker-dev           # Start Miniflare
make worker-generate-secrets  # Generate .dev.vars
make worker-login         # Login to Cloudflare (for integration)
```

### Terraform
```bash
make tf-init ENV=local    # Initialize Terraform
make tf-plan ENV=local    # Plan changes
make tf-apply ENV=local   # Apply changes
make tf-fmt               # Format all .tf files
make tf-validate          # Validate configuration
```

### Database
```bash
make db-shell             # Open PostgreSQL shell
make db-reset             # Reset database (WARNING: destroys data)
```

### Utilities
```bash
make help                 # Show all targets
make version              # Show tool versions
make clean                # Clean generated files
make clean-all            # Clean everything including Docker volumes
```

## Configuration

### Environment Variables

Local development uses `.dev.vars` (generated by `make worker-generate-secrets`):

| Variable | Description | Default |
|----------|-------------|---------|
| `ENVIRONMENT` | Environment name | `local` |
| `LOG_LEVEL` | Logging verbosity | `debug` |
| `POSTGRES_CONNECTION_STRING` | Database connection | `postgresql://cssuser:csspass@localhost:5432/cssdb` |
| `FIRESTORE_PROJECT_ID` | Firestore project | `local-css-project` |
| `FIRESTORE_EMULATOR_HOST` | Emulator address | `localhost:8080` |
| `CORS_ORIGINS` | Allowed origins | `http://localhost:3000,...` |

### Wrangler Configuration

The `workers/wrangler.jsonc` file defines:

- **Durable Objects**: `DocumentState`, `PresenceManager`, `SessionManager`
- **KV Namespaces**: `CONFIG_KV`, `SESSION_KV`
- **Environment overrides**: `sbx1`, `production`

### Terraform Environments

| Environment | Backend | Purpose |
|-------------|---------|---------|
| `local` | None (`-backend=false`) | Local development |
| `sbx1` | GCS | Sandbox testing |
| `production` | GCS | Production deployment |

## Service Endpoints (Local)

| Service | Port | URL |
|---------|------|-----|
| PostgreSQL | 5432 | `postgresql://cssuser:csspass@localhost:5432/cssdb` |
| Firestore Emulator | 8080 | `http://localhost:8080` |
| Miniflare Worker | 8787 | `http://localhost:8787` |
| pgAdmin (optional) | 5050 | `http://localhost:5050` |

To start pgAdmin: `docker-compose -f docker/docker-compose.local.yaml --profile tools up pgadmin`

## Pantheon Standards Compliance

This infrastructure follows Pantheon conventions:

- **Makefile** as primary task runner
- **pan-*** tagging convention for resources
- **pnpm** as package manager
- **wrangler.jsonc** (not TOML) for Cloudflare config
- **Terraform modules** for environment abstraction
- **Docker Compose** for local services
- **Scripts** in `/scripts` directory

## Troubleshooting

### Docker services not starting
```bash
# Check Docker is running
docker info

# View container logs
make docker-logs

# Restart services
make docker-restart
```

### Miniflare errors
```bash
# Ensure .dev.vars exists
make worker-generate-secrets

# Check Node version (20+ required)
node --version

# Reinstall dependencies
rm -rf workers/node_modules && make worker-install
```

### Terraform initialization fails
```bash
# For local env, use -backend=false
cd terraform/environments/local
terraform init -backend=false

# Or use Makefile
make tf-init ENV=local
```

### PostgreSQL connection refused
```bash
# Check container health
docker-compose -f docker/docker-compose.local.yaml ps

# Wait for healthy status
./scripts/wait-for-services.sh
```
